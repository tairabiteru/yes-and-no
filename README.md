# Heyo.
If you find yourself here, it can only be because you were poking around, perhaps wondering what this is. **This repository does not hold anything useful.** What is here is not even here for you, it's here for me, because this contains the earliest *vaguely* functional piece of software I ever wrote. It is a reminder to myself of exactly how far I've come as a programmer.

I will reiterate: **don't run this**. It requires an old ass version of Python 2 and probably features a stupendous number of bugs. Hell, it's not even finished. It is not interesting. It will absolutely NOT be worth your time to go and figure out which freaking old ass version of Python this is supposed to run and get this thing running. If you want, you can read the code and look at the comments in there, but that's all this is good for. A foray into how far I've come.

## So what is it?
Well, it's a game, and I use that term EXTREMELY loosely. It's incomplete, and it is played entirely in the terminal. It is essentially a series of choices whose *correct* answers are mostly predicated on you having played the game enough to not make a mistake. In fact, sometimes you can randomly lose by design through no fault of your own. (Great game design, I know.)

The exact date this was written has been lost to time, but it had to be sometime around 2013 if I had to guess. At this point in time, I was just entering college to pursue a degree in computer science, and had been introduced to Python via a class titled "Introduction to Programming Logic." A glance through the code quickly reveals a snapshot of my programming prowess at that time:

1. The code is around 870 lines long.
2. It contains 8 function definitions.
3. It imports three standard libraries.
4. Every single variable is declared in the global namespace.
5. It contains zero class definitions.

This was written at a time when I had a pretty firm grasp on how conditionals worked, and knew how to retrieve input and display output via `print` and `raw_input()`. (Good god, I can't even remember the last time I *typed* "raw_input()".) I was just *barely* starting to get comfortable with functions, and I had zero concept of classes, methods or any OOP specific concepts. In fact, I don't even think I really have any loops in here...I figured out how to use `random.randint()` though so...there's that.

Look, I'm not going to sugarcoat it: this code is bad. Objectively bad. **TOXIC NUCLEAR WASTE BAD.**

But just like nuclear waste being difficult to get rid of, I find myself hanging on to this file. For me, that file that [Peter Welch says every programmer has on their computer](https://www.stilldrinking.org/programming-sucks) doesn't contain good code. Instead, it's there to remind me that even if I feel stuck at times, the momentum I've built up is impressive, and even if I started from simple, humble...kind of disgusting roots to be honest, the strides I've made are proof that it's a pursuit worth continuing; The results of the continual striking of the hammer of knowledge and progress.
